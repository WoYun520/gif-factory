# 场景与视觉规格

本页的构图、连续性与可读性适用于三个内容分支。视觉起步值以摄影纸艺为默认；选用[彩色贴纸](color-stickers.md)或[复古档案](retro-archive.md)时，读取对应分支的材料、配色、字体和动作。用户提供的构图、尺寸和风格优先，不要求同样时长或同样分六场。

## 让内容看得见

一个镜头先确定主动作，再安排环境、工具和结果。每件物件应说明操作或关系。生活机关和机械特写以结构清楚为先，金融场景以人物业务动作和连续账目为先；不按相同道具数量填满三个分支。

| 层次 | 生活机关与机械 | 金融场景 |
| --- | --- | --- |
| 背景或定位 | 完整外壳、固定框架、整机缩略图 | 业务场景、参与方设备或档案页 |
| 核心动作 | 链牙合拢、凸耳分度、齿轮与叉瓦联动 | 贴券、签约、递交、入账、还本、结算 |
| 参照与标注 | 轴心、导向、剪切线、同一零件跟踪 | 凭证、账户、交易方、资金路径 |
| 可读结果 | 扣合、卡住、放行、复位、轮速变化 | 资产负债与余额变化 |

实物全景、内部剖面、展开图、桌面特写和关系示意要有区别。不能只换标题、晃动整张图，或用无关图标、现金燃烧、光效和持续漂浮填空。摄影纸艺的三维机构保留统一金属材质和暖白轮廓；其他风格按其媒介处理，空间与接触关系始终以模型为准。参与方也可以通过手机、店铺、设备或凭证表现，不强制每个金融镜头都有人物。

## 摄影纸艺起步值

| 项目 | 起步值 |
| --- | --- |
| 画幅 | 新片起步原生1080×1920、30fps；续作沿用用户已选画幅 |
| 色彩 | 黑纸#242321；暖白#eee7d7；墨色#171612；强调黄#f0b323 |
| 素材 | 灰度摄影剪贴，少量材质暖色；细窄暖白撕边 |
| 字体 | 标题用清晰中文黑体，字幕用可读宋体；按环境选择合法可用字体 |
| 主标题 | 约78–100px，通常一行，减少重复大字占位 |
| 核心读数 | 约110–150px，适用于金额、圈数等；避免遮住接触点与单位 |
| 步骤标签 | 约38–48px，正文纹理与必须阅读的文字分开 |
| 字幕 | 约46px，黑底暖白宋体，位置参考y1180 |
| 主要信息 | 原生竖屏可参考x80–980、y240–1160，按实际机构与平台重新检查 |
| 外缘与底部 | 道具和桌沿可延伸到y1600–1900，关键数值不放到界面遮挡区 |
| 作者与脚注 | 默认不加个人水印、“虚构案例”条和配乐署名条 |

这些坐标来自竖屏金融样例，不是方形或所有平台的统一安全区。早期机关片为1080×1080主画面，导出竖屏时上下各420px留边；接续该版式时保留比例，字幕随主画面一起重新检查。新作可以原生竖屏，不硬套黑边。

封面保留实物或业务主问题，手机尺寸下看清接触关系或主要数值。字体按环境与许可选择，不随开源包分发没有再分发授权的本机字库。

## 节奏与连续性

第一帧就有实际内容，前三秒让问题和主物件读得清楚。通常每两三秒有一次有意义的新信息；接触、锁止、数字落定和对照结果留出阅读时间。保持模型锁止或给观众读数时可以有意停留，不给每个零件添加无意义晃动。

同一颗链牙、同一枚凸耳、同一根轴和同一张凭证跨镜头保持身份。机构切剖面、换坐标或展开时，先建立对应关系；人物衣着与道具比例也保持。印章压下才出现印迹，资金沿有起终点的路线移动，接触与结果都能读清。

同一对象的状态要接得上：按动笔第一次松手停留、第二次松手回缩；差速器轮数相容；已还本后结尾继续剩90万。比喻不能替代物理结构或实际资金过程。各分支的具体模型要求见相应分支说明。
