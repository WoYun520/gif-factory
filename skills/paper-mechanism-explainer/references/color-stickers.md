# 彩色贴纸风

用于把物件、参与方和因果关系做成可独立移动的二维插画贴纸。既有方法来自《大包装一定更划算吗》《优惠券到底谁买单》；参考[实际成片抽帧](../assets/color-stickers-reference.jpg)。它们验证了消费与金融题的表达方法，换成生活机关或机械结构时仍要建立新的结构模型。

## 场景与材料

- 以奶油纸底、彩色印刷插画、深色轮廓和清楚的白色刀模边建立识别。主物件保持完整，纸质纹理来自素材本身，不给照片套白框冒充插画。
- 参与方可用顾客手机、商家店面、平台电脑表示，旁边配清楚的角色名称；没有必要时不增加人物。店面采用二维正面或清楚的平面插画，不做微缩透视与三维人偶。
- 一支片维持同一组商品和角色。跨镜头保留物件身份、比例和对应关系，按讲解重排位置；底部台面和道具承接场景，不能抢走主要金额与动作。
- 每件道具承担识别、操作、比较或核对功能。避免把画面变成浮空图标、密集信息卡、金币雨或无限弹跳。

| 项目 | 起步值与用法 |
| --- | --- |
| 配色 | 奶油#f7f1e3、深绿#29432f、番茄红#c3422c、柠檬黄#f6d76b，浅绿作台面或辅助区别 |
| 主要信息 | 原生1080×1920示例集中在x108–972、y168–1340；按平台与主体重新核对，不当成统一安全区 |
| 字体 | 清楚的中文黑体配圆润数字；标题约65–102px，重要金额约86–139px，单位和步骤约32–44px |
| 关键文字 | 价格、容量、主体名称、金额和字幕独立排版，不从生成图里读取 |
| 层次 | 背景、连续物件、贴纸标签、路径、字幕分层；核对移动过程中是否挡住角色名、单位或结果 |

一支片不必同时使用全部颜色。读数与单位需要在360px宽预览中一起看清，不能只放大数字、缩小“元”“mL”或省略项。

## 动作组织

先定义物件起点、终点、接触和触发时刻，再做动效。已用的起步节奏是贴纸落位0.30–0.42秒、位置重排约0.48–0.50秒、商品交接约0.9秒；根据实际旁白调整，不规定每张贴纸都弹一次。

持续承载主物件，而不是每切一场就销毁再弹入。标签出现、箭头绘制和主体移动错开，动作引导视线到当前解释点。结尾落定后保留读数时间，最后一帧继续显示结果。

画资金流时，款项从实际付款方走向实际收款方，数字保持正向，到达时才改变收款牌。路径和账目读取同一事件时刻；多个独立假设有明确切换，不把先前补贴累加。优惠券的让利与补贴条件见[金融机制](finance-mechanisms.md)中的案例。

画生活机关时，白边外观只负责识别。准确链牙、弹子或凸轮采用可编辑的平面剖面，与外部贴纸建立对应关系；不让整张贴纸的位移代替内部接触、锁止或释放。

## 原生透明素材

生成图需要独立移动时，明确请求原生透明PNG。可以把少量角色放在同一素材板上，保留足够裁切间隙和完整白边；字号与金额留给工程添加。

> 原创二维印刷贴纸插画素材板，奶油、橄榄绿、番茄红和柠檬黄，手绘墨线、轻微纸张质感、完整白色刀模边。四个互不重叠且四周留足空隙的独立物件：空白屏幕的顾客手机、无品牌的商店正面、空白屏幕的平台电脑、带空白小票的商品纸袋。各物件完整可单独裁切，统一画风；无文字、价格、数字、品牌和水印。平面插画，不用照片、三维人物或微缩场景。原生alpha透明PNG，主体外真正透明，无棋盘格、底色、雾状边缘或投影底。

按题目替换物件；不要把本例的手机、小店和电脑变成所有题材的固定道具。使用旧图统一画风时，记录参考的是自己的哪张图，以及保留的是画风还是具体物件身份，不复制同行整套构图。

检查未改写的原始PNG及浅色、深色底边缘。独立贴纸若只做矩形裁切，保留裁切坐标与源RGBA像素；需要抠图或修边时如实记录，不继续称为未经后处理的原生素材。

## 复查重点

- 看主物件完整轮廓、白边、设备屏幕与叠加文字的对齐；同一商品的容量由标签和模型说明，不靠插画视觉大小证明。
- 看每次跨镜移动的起中末、角色名与单位遮挡、商品交接和路径到达前后。
- 对金额直接显示正确的完整值，不让计数动画滚过没有发生的收款或余额。不同情形的重置保持清楚。
- 第一帧即有问题与物件；最终对照、规则说明和结果章不能碰到背景分界线、桌沿或字幕，也不能在末帧消失。
- 既有示例的共同基准与公式段需要停留阅读，商家承担段没有补贴现金移动；可加强优惠条与订单的关系，不添加不存在的资金流制造热闹。

公开默认无个人水印、固定栏目名、案例底条和配乐署名条。配音、交付与素材许可沿用[制作与检查](production.md)，不随风格切换额外下载语音模型或改用未经选择的声音。
