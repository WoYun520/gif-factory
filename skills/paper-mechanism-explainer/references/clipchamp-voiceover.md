# Clipchamp 旁白与声线试听

在用户选择 Clipchamp 配音、选定其中的声音，或只要求制作一段旁白时读取。本流程通过可用的浏览器操作微软网站，仍需在线合成；不提供离线模型，不调用未公开接口，也不把网页免费功能描述成免费 API。账号、登录状态和服务可用性由用户自己的环境提供。

## 读稿、选声线、检查复用

先保存实际要朗读的 UTF-8 文本。当前明确要求优先，其次读取当前工程或项目根目录的 `voiceover-profile.json`，再沿用本项目已验收的声线；不要为了换视觉风格更换声音。配置只记录偏好，外部服务的使用范围仍以当前用户请求和有效历史授权为准。不要把某一用户的授权带给其他安装者。

下面是可选的中文男声起步配置，其他用户可以换声线；不要覆盖已有选择：

```json
{
  "provider": "clipchamp",
  "language": "zh-CN",
  "voice": "Yunjie Dragon HD Flash Latest",
  "pitch": "default",
  "speed": 1.0
}
```

界面中选择“中文（普通话，简体）”，声音完整名称以配置为准。此例是云杰 HD，普通 `Yunjie`、Edge TTS 同名声音或其他 HD 声线不视为同一选项。配置声线消失时说明情况，让用户选择替代，不静默降级。首次选声可交付短样；已经选定后直接处理正式稿，不为每期重复做选声审批。

在工程自己的缓存目录中检查原稿、服务、语言、完整声线名、声调与语速。文字包含标点和停顿；任一项改变都不能冒用旧音频。只换画面、重新剪辑或做合集时直接复用已有成品旁白。辅助工具只管理本地缓存，不联网。下列命令的脚本路径以 Skill 根目录为基准，输入稿件、配置和缓存路径按实际工程替换：

```bash
python3 scripts/voiceover_cache.py lookup --text narration.txt --profile voiceover-profile.json --cache-dir audio/voiceover-cache
```

`hit` 表示对应文件存在且校验值匹配，可直接复用；`miss` 才进入生成流程。它核对的是请求参数与文件完整性，不能从音频推断声线身份或逐字内容。明确要求重配时优先遵从用户要求，为新版本另设输出目录，保留旧版。

## 网页生成与导出

使用当前环境实际可用的浏览器工具，先读它自己的操作说明。有足够能力的 Clipchamp 专用连接器时优先使用。浏览器说明中的页面控制、登录交接与收尾规则继续适用；不要把本机 CLI、账号或某次页面编号写成所有用户的必需条件。

1. 打开 [Clipchamp](https://app.clipchamp.com/)，续作先检查已有工程；没有工程时新建。登录、验证码或二次验证交给用户本人，完成后在同一任务页面继续。保持登录有效时不要求用户每期重新登录。
2. 进入“记录和创建 → 文字转语音”，按项目配置选择语言、完整声线名、声调和语速。输入本次实际原稿，核对显示的文字及声音选项后保存。不要借口语化擅改数字、意思或台词。
3. 需要试听时预览；正式配音按完整稿生成。超过当前界面长度限制时按语义分段并核对衔接，不截取开头冒充完整旁白。声音列表一直加载时先检查状态、有限等待，必要时刷新同页；持续失败就保留本地稿并报告，不反复新建工程。
4. 等待生成结束，再检查时间线的旁白、时长及片段数量。返回编辑页后，先选中原旁白音轨再打开文字转语音；界面可能留下空白占位条，避免误往别的轨道加旁白或导出叠音。
5. 选择“导出 → 纯音频”，按当前界面支持的格式下载。已验证的界面导出 M4A；若工具要求 MP3，再本地转换并保留原始文件。下载需真正保存到可访问的本地路径；仅点预览不算交付。

网页操作使用当次观察到的控件，不复制旧的按钮编号、坐标或会话地址。只用免费功能；出现购买要求时保留稿件并说明，不能自行开通套餐。不要复制 Cookie、访问令牌、私有请求地址或用户账号到工程和开源包。

## 存档与交付

使用 FFmpeg/ffprobe 检查实际音频有可解码的音轨、时长大于零，再按需要转换格式。以当前环境实际可用工具完成，不为格式转换另调用配音服务。浏览器中核对过原稿与声线后，可把下载并验证的音频登记为缓存：

```bash
python3 scripts/voiceover_cache.py record --text narration.txt --profile voiceover-profile.json --cache-dir audio/voiceover-cache --audio narration.mp3
```

此工具保存原稿、参数、音频副本和校验值；不会覆盖已有缓存条目。缓存中有稿件和生成媒体，留在用户工程里，不随 Skill 开源分发。只把可复用的说明和工具放进 Skill，项目的个性化配置也不自动发布。

交付可直接播放的本地音频，标清声线、实际时长和使用的服务。支持内嵌媒体的环境使用其音频播放器；不要让用户只去网页找播放按钮。技术解码通过不能冒充人耳试听或自然度验收。制作视频时用实际旁白时序安排镜头。
