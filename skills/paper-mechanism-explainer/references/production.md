# 制作与检查

## 准备环境与选题

先查看现有工程、最近成片和用户最新反馈，分别确定内容分支与视觉分支。生活机关、机械结构或金融机制决定模型；摄影纸艺、彩色贴纸或复古档案决定表现方法。读取对应风格说明；续作保留已选风格，没有可接续的选择时以摄影纸艺起步。只有选题需求时不启动配音或渲染；已经批准制作时按当前范围继续。优先选择能追踪一个零件、一条传动链或一笔钱讲清楚的问题。

需要能得到素材、按需取得旁白、组合并渲染视频的环境。可编辑几何负责精确的机构和轨迹，不强制为这些结构生成图片。HyperFrames是一种已验证的组合方式，另需Node.js、FFmpeg、ffprobe；检查脚本只用Python标准库。图像与语音服务不随仓库提供，不写入密钥，不预设他人的额度或授权。

## 从机制到镜头

已有旁白时先读取原文、音频与可用时序，按其组织镜头，不因更换风格自动重写或重新发送配音；没有旁白时再形成简短稿。为每个解释点写“起态 → 操作 → 末态”。查原理资料，明确结构类型、模型坐标、事实、未知数和省略项。按用户已选择的方案做片，不追加整轮审批。不同领域的具体关系和检查点只在对应分支中读取。

机构片先建立输入、从动、固定、接触和状态转换表；确认坐标正向、父子运动组、运动周期以及最终停留或复位。金融片先建立参与方、收付和余额表。可放慢动作或放大细节，但不能改变因果关系。

用同一模型驱动实物、剖面、三维、展开图、指针、数字和标签。几何明确单位与容差，金额用整数最小货币单位。对接触、锁止、转向、账目和最终状态作相应审计；正向播放、直接定位和逆序定位应一致。规则写进与当前模型匹配的脚本，不把某例的通过记录当通用保证。

## 素材与声音

新场景使用原创构图，参考只保留需要的外观、身份、材质或节奏，不复制同行整套画面。实际查看参考图后再编辑，诚实记录是否使用了参考图片。人物场景可分背景、操作与前景；机构场景分外壳、固定件、运动件和标注，不要求无关环境道具。

摄影/生成图负责外观和纹理，准确的链牙、齿轮、凸轮、弹子和轨迹由可编辑几何实现。彩色贴纸需要原生透明插画与可独立移动的物件；档案记录需要身份一致且能交代操作的照片与独立账纸。透明素材要求原生alpha时，保留原文件并检查alpha与实际浅色/深色底边缘；不能把棋盘格或后期抠图说成原生输出。关键文字、数字与印章文字另排。

配音用用户已选的声音，样例为中文男声，原配音使用Edge TTS的zh-CN-YunxiNeural、+10%；这只是可替换的案例参数。使用环境里实际可用且已获授权的服务，或导入本地旁白。拿到实际音频和分句/逐词时间后再定镜头时长。

有旁白时配乐轻放并避让人声，咬合、咔哒、滴答、盖章或入账配置少量准确音效。锁止发生时才响，不把每帧运动配成连续乱响。使用录音或合成声音如实标明，不能声称做过机构声学仿真。不要使用同行原视频音轨；需要署名的音乐附发布文案与来源。

## 组合、检查、导出

使用HyperFrames时读当前环境相应技能；缺少时按官方CLI文档完成环境配置，不假装工具已装。现有工程沿用固定版本，不为一次文字修改升级全套依赖。新建每场独立组合，字幕、品牌、场景和音轨可分别修改；公开默认不挂作者水印。

先检查工程能否加载、文字是否溢出，再看关键帧和手机预览。少量文字修改检查对应位置及片尾；改镜头或节奏时检查全部切点。机构重点看接触、锁止、释放和复位前后，金融重点看盖章、递接、路线与余额变化。贴纸另看完整轮廓、跨镜移动、资金到达与入账同刻；档案另看照片裁切、纸页遮挡、红笔与落章、单位和公式的阅读时间。遮挡、穿插或错误相位应修模型与锚点，不能靠快速剪辑或模糊掩饰。

按正常速度播放一次完整片段。导出后对实际MP4检查尺寸、fps、时长、帧数、音轨；解码抽看片头、金额变动和片尾。配音优先，常见发布起点约-16 LUFS、真峰值不超过-1dBTP，按用户平台要求调整。只有技术测量时不能声称已经人耳验收。

本Skill检查工具示例：

```bash
python3 scripts/inspect_delivery.py film.mp4 --fps 30 --width 1080 --height 1920 --cover cover.png --archive project.zip --full-decode --out delivery-check.json
```

按实际画幅修改宽高，有明确片长时加 `--duration 秒数`。成功退出只代表列出的文件检查通过；结构正确性、金融含义、画面内容、遮挡与口播是否自然仍需单独判断。

交付MP4、同风格封面、包含本地素材和相对路径的可编辑工程。ZIP排除缓存、依赖目录、密钥、私人参考原件与机器绝对路径。源码与文档可依仓库MIT许可；音乐、字体等另按各自许可，不能一并改标为MIT。公开案例提供可看成片与来源，不默认发布每一份用户素材或内部工作记录。

本地交付完成后停止。只有用户明确要求同步或发布，才处理GitHub、PR或内容平台；“准备开源”和“继续制作”本身不是同步指令。
