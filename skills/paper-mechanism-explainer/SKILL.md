# vibe 知识大赏

把一个熟悉物件背后的机关，或不熟悉的金融规则，变成能看见的动作和结果。内容分支决定原理与模型，视觉分支决定素材、场景和动作语言；先选题，再沿用或选择风格。方法来自《世界的小机关》及贴纸、购物档案等既有成片，不固定栏目名或镜头数量。

这是制作方法与检查工具，需要可用的视频渲染环境，以及本地素材或相应的生成工具；几何绘制的机构不必调用图像生成。安装本 Skill 不会附送模型、服务额度或渲染器。公开版默认无个人水印、无固定作者名、无强制系列名。

**立体剖面联动使用外部 Skill。** 该分支实际调用 [Lemo-Opuscar by Lemomo（LemoLab）](https://github.com/lemomo-ai/lemo-opuscar) 的 `lemo-opuscar` Skill，按其分色机械图解风格制作。本包提供调用说明和项目案例；上游 Skill、风格文档及渲染运行时需另行安装，按上游许可使用。选中时读取[外部 Skill 工作流与署名](references/lemo-cutaway.md)。

## 接续用户的要求

- 只要选题或方案：给最有把握的切入点、开头问题和可拍的场景，先不制作整片。
- 只要旁白或声线试听：按用户选择的服务生成并交付可播放的音频，不启动整片渲染；使用 Clipchamp 时读取[Clipchamp 配音](references/clipchamp-voiceover.md)。
- 已批准“可以”“开始”或明确要求制作：沿用当前选题、素材、声线和格式，继续做到可看的成片，不重复要求确认同一方案。
- 反馈“画面简陋”：检查主动作、人物互动、景别、前中后景和物件关系。改场景内容，不只增加标题、图标和转场。
- 修改已有片：先读当前工程与最新验收记录，只改用户指出的内容。画面修改可复用已有旁白，不重新发送配音请求。

## 共同叙事与画面

开头从实际物件或日常问题进入，前三秒让观众知道要解释什么；随后追踪一个零件、一次操作或一笔钱，解释关键关系，最后回到原问题。别用连续术语定义开场，不编造事实制造冲突。

生活机关与机械片常用“完整实物 → 剖面或拆开 → 接触与联动 → 结果 → 回到实物”；金融片常用“参与方操作 → 凭证与账目 → 资金或余额变化 → 约束 → 结果”。按内容组织，不固定六场，也不强制每场重放大标题。

每个解释点安排可见动作：合拢、卡住、释放、转动、复位，或签、递、记、盖、划转。物件有接触点和前后状态，出现人物时让他们做具体事情。画面丰富度来自清楚的因果关系；机构特写可以只有少量关键零件，不套用营业厅的人群与道具数量。

标题、标注和数字在工程里排，不依赖生成图准确写字。人物采用摄影或平面插画，不使用三维人偶。摄影纸艺机构可以用平面剖面，也可以用金属材质的三维几何；贴纸和档案的结构表现按对应分支处理。精确运动件由可编辑几何和运动模型驱动，生成图按需负责实物外观、环境和材质。

内置风格的新片起步1080×1920、30fps；外部立体剖面分支按上游规范或用户已选格式。时长由真实旁白、操作和阅读时间决定。接续旧片时沿用用户已选画幅；早期样例的方形主画面加竖屏留边也可继续使用，不拉伸、不擅自改版。方形、横屏和GIF按请求另做。

## 原理与模型要跟得上画面

先核实机制，记录关键说法的原理资料与模型范围。生活机关要确认具体结构类型，机械片要明确二维、三维与观察坐标，金融片要区分示例条件、制度和实际产品。新题目重新查证，不能把样例参数当通用规则。

每期有一份统一状态模型：位置、角度、接触、锁止与复位，或交易、金额与余额。跨剖面、三维、展开图、计数器和结尾共用它。检查中间过程与逆序定位，不能只比较首尾。机构运动示意不等于制造或受力仿真，金融示例不等于真实报价或收益承诺。

必要范围通过旁白、对应步骤标签和工程说明交代，不加重复的“虚构案例”底条。放慢运动或改为随外壳观察时保留必要提示。配乐署名放在随附来源及发布文案，画面不显示配乐署名条。

## 制作与交付

内置风格的具体顺序、配音、图片、渲染与导出见[制作与检查](references/production.md)；立体剖面先读[外部 Skill 工作流](references/lemo-cutaway.md)，再使用已安装的 `lemo-opuscar`。素材提示词按所选风格读取，不把纸艺摄影提示词直接套给彩色贴纸或档案照片。

以真实旁白的分句或逐词时间安排咬合、锁止、释放、入账和结算，别用字数估计代替最终时轴。配音跟随当前用户选择，外部服务的使用依当前对话授权，不把案例授权写成对所有人的默认许可。

使用 Clipchamp 时，按[Clipchamp 配音](references/clipchamp-voiceover.md)读取项目的 `voiceover-profile.json`，完成网页生成、纯音频导出与本地复用。云杰 HD 是可选起步声线，公开版不强制所有用户使用；项目已经选定的声音优先。此流程仍需微软在线服务，安装 Skill 不会获得离线声音模型或免费 API。

内置分支使用 HyperFrames 时读取环境中的对应技能并沿用已有工程固定版本；外部立体剖面沿用 lemo-opuscar 的渲染工具。每场独立可编辑，字幕、场景、音频分层，所有变化能按时间直接定位。仅检查通过不代表观感合格：看手机尺寸、切点、接触动作和实际导出帧。

交付主片、同风格封面、可编辑工程和必要素材说明。公开视频与封面默认无个人水印，不加底部案例条或配乐署名条；必要机制范围通过旁白或步骤标签交代。用户明确要求品牌时才加。没有实际导出文件时，明确当前只完成了脚本或分镜。

交付不等于发布。仅要求制作或准备开源时先完成本地文件；没有明确同步请求，不推送GitHub、创建PR或发布到内容平台。

使用 `scripts/inspect_delivery.py` 检查实际文件：

```bash
python3 scripts/inspect_delivery.py film.mp4 --fps 30 --cover cover.png --archive project.zip --full-decode
```

方形片加 `--width 1080 --height 1080`；立体剖面横屏片用 `--width 1920 --height 1080 --fps 24`；有明确片长时加 `--duration 秒数`。该工具只检查文件，不代替机构或金额审计、视觉验收与人耳试听。本包收录三种内置风格的制作说明，以及立体剖面联动的外部 Skill 入口和本期参考抽帧，不包含完整渲染工程或上游运行时；新题目仍需自己的模型与验收。
