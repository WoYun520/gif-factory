# 制作与检查

## 准备环境与选题

先查看现有工程、最近成片和用户最新反馈。只有选题需求时不启动配音或渲染；已经批准制作时按当前范围继续。优先选择能用一笔钱和少量角色讲清楚的机制，例如分期费用、贷款与存款、交易结算；选题不等于实际产品推荐。

需要能生成图像、得到旁白、组合并渲染视频的环境。HyperFrames是一种已验证的组合方式，另需Node.js、FFmpeg、ffprobe；检查脚本只用Python标准库。图像与语音服务不随仓库提供，不写入密钥，不预设他人的额度或授权。

## 从机制到镜头

先形成简短旁白和数据模型，再为每个解释点写“起态 → 操作 → 末态”。查关键机制的官方来源，记录日期与适用范围。明确示例数值、事实、未知数和省略项。按用户已选择的方案做片，不为了展示流程追加整轮审批。

以贷款样例说明数据约束：本金100万元，直接用本行该存款归还10万元本金，两边剩90万元；没有先把全部存款花掉，也不把净资产变化0元说成总财富0。这个模型只用于此样例，新题目需换模型。

金额统一以整数分等最小单位存储，所有界面、数值和余额从模型派生。角色、道具和资金状态另列连续性表。数字同步动画还要看实际中间帧，不能只比较首尾。

## 素材与声音

新场景使用原创构图，参考只保留需要的身份、材质或节奏，不复制同行整套画面。背景、人物动作、前景工具可以分层生成；同一场景的光线、视角与比例应相容。实际查看参考图后再编辑，诚实记录是否使用了参考图片。

透明素材要求原生alpha，保留原始文件并检查alpha与黑/暖白底边缘；没有原生透明时不能把棋盘格或后期抠图声称为原生输出。关键数字、合同名、字幕与印章文字在可编辑工程内排版。

配音用用户已选的声音，样例为中文男声，原配音使用Edge TTS的zh-CN-YunxiNeural、+10%；这只是可替换的案例参数。使用环境里实际可用且已获授权的服务，或导入本地旁白。拿到实际音频和分句/逐词时间后再定镜头时长。

有旁白时配乐轻放并避让人声，盖章、入账或切景配置少量准确音效。不要拿同行原视频的音轨作为公开素材。优先用原创、用户已授权或无需署名的音乐；需要署名时提供发布文案与来源说明，画面保持干净。

## 组合、检查、导出

使用HyperFrames时读当前环境相应技能；缺少时按官方CLI文档完成环境配置，不假装工具已装。现有工程沿用固定版本，不为一次文字修改升级全套依赖。新建每场独立组合，字幕、品牌、场景和音轨可分别修改；公开默认不挂作者水印。

先检查工程能否加载、文字是否溢出，再看关键帧和手机预览。修改少量文字时检查修改位置及片尾即可；改了镜头或节奏时检查全部切点与关键动作。数字、签字、盖章、递接、结算路线的接触前后要看连续帧。

按正常速度播放一次完整片段。导出后对实际MP4检查尺寸、fps、时长、帧数、音轨；解码抽看片头、金额变动和片尾。配音优先，常见发布起点约-16 LUFS、真峰值不超过-1dBTP，按用户平台要求调整。只有技术测量时不能声称已经人耳验收。

本Skill检查工具示例：

```bash
python3 scripts/inspect_delivery.py film.mp4 --fps 30 --width 1080 --height 1920 --duration 42.733333 --cover cover.png --archive project.zip --full-decode --out delivery-check.json
```

成功退出只代表列出的文件检查通过。金融含义、画面内容、数字遮挡、口播是否自然仍需单独判断。

交付MP4、同风格封面、包含本地素材和相对路径的可编辑工程。ZIP排除缓存、依赖目录、密钥、私人参考原件与机器绝对路径。源码与文档可依仓库MIT许可；音乐、字体等另按各自许可，不能一并改标为MIT。公开案例提供可看成片与来源，不默认发布每一份用户素材或内部工作记录。
