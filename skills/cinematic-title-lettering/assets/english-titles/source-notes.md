# 英文片头的图片与字体

50张封面均由内置生图工具按字体和装饰参考制作，前十张沿用已选装饰稿。`prompts.json` 保存实际提示词及最后修正，`catalog.json` 对应 EN、R、字体、原图和授权文件。

图中的装饰字稿是单个片名的设计；`fonts` 里是其基础字体的原始 TTF。文档与脚本的 MIT 许可不替代字体自己的 OFL 或 Apache 许可，字体原许可随文件保留。
