# 电影片名字形

从用户给的片名、题材和情绪出发，为具体文案设计字形和排布。保留用户指定的简繁、标点、英文大小写与断行。用户提供已定稿的字标并要求排版时，直接使用该字标。

1. 从标题里找一个值得表现的动作、物象或情绪。决定它影响哪一笔、哪个字的重心或整组字的间距。例如以错开的收笔表现风向，以有停顿的字距表现潮汐。给一句话也能讲清的视觉关系，留出能读字的空间。
2. 先定字组的轮廓和阅读顺序，再定笔画粗细、质感和颜色。参考图可帮助理解飞白、网点、衬线或疏密等手法。根据新字自己的偏旁和笔顺重建骨架，从题材出发重新设计独特装饰、长笔和中英文字的位置。
3. 生成或绘制独立字标。提示词直接写确切文案、字形关系、配色和交付底色。需要比较多个方向时，用同一片名对照字形与排布。需要给同一方向换文案时，根据新字重定宽窄、字距和重心。
4. 放大核对字数、偏旁、标点和副题，缩小检查读序和笔画是否糊在一起。透明稿检查长笔、飞白、闭合部件和笔缘。

需要叠实拍、配宣传图或排三幅竖列时，读[三幅实拍竖列宣传图](references/promo-triptychs.md)。用已确认的字标和有明确来源的照片，按镜头留白分别调整字标位置与比例。
