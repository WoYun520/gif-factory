# 40 类电影片名字形

用 F01–F40 选择字形结构，再为新片名和镜头重画。这里的 40 类是创作方向，每类都有已保存的片头案例；不是四十套覆盖全部汉字的可安装字体。8 个分组仅帮助浏览，色彩、题材、片名和排法不另计为分类。

## 选择与延续

1. 根据故事选 2–4 类，先看该类的原图，再读结构与相近类别的区别。没有指定方向时，从情绪、字数和镜头留白选；不要只按主题词套字。
2. 为新片名写下具体的用笔方式、偏旁宽窄、字腔与断连关系。保留该类的构造，重建新字，不机械挪用案例轮廓。
3. 让字有个人习惯：某些偏旁挤窄、重心偏开、短笔笨一点、长笔有停顿。特别之处应落在字的骨架与笔性，仍能逐字辨认；不要把每款修成同一套流畅、匀称的书法字。
4. 按[电影片头方法](film-title-frames.md)选择摄影场景、字组位置、主色与英文留白。能依附于笔画、字腔和收笔的细节才加入，不靠独立小图标补足设计感。
5. 成组时比较字骨、笔画构造和内腔。仅改颜色、大小、断行或背景不算新类；对看起来相似的案例，用表中的区别检查，必要时重新设计。

字形编号使用 **F 前缀**；[五种排法](layout-recipes.md)的 01–05 是另一条选择轴，不能拿排法编号代替字形。延续当前系列时保留下面已选十款的原版，后续试验另存版本。

## 记录与复用

[分类数据](../assets/style-catalog/catalog.json)记录 40 个唯一编号、结构、相近区别、案例路径、状态、实际尺寸与 SHA-256；它是分类索引的数据源。[已选十款记录](../assets/style-catalog/selected-prompts.json)和[新增二十款记录](../assets/style-catalog/new-prompts.json)保存确切文案、方向与提示词。早期十款的来源见[照片与制作边界](../assets/film-title-examples/source-credits.md)。

F11–F40 使用用户提供的电影标题设计局部作为风格参考，标题与摄影式场景重新生成；不是原始实拍照片。公开包不包含第三方参考原图、聊天截图或私人路径。记录了参考标识与裁切角色；缺少原图时只能按文字延续方向，不能称为同输入复现。即使输入相同，重新生成也不保证像素一致；精确保留本轮结果使用存档 PNG。

总览只从成品拼排，保持原图内容与宽高比，不重画艺术画面。在 Skill 目录中运行（Python 3 + Pillow）：

```bash
python3 scripts/render_style_catalog.py --select new --out-dir /tmp/title-new
python3 scripts/render_style_catalog.py --select selected --out-dir /tmp/title-selected
python3 scripts/render_style_catalog.py --select all --out-dir /tmp/title-catalog
```

默认每页十张，`--select all` 生成四页；可调整 `--columns`、`--page-size`、`--tile-width`。中文标题需要覆盖汉字的字体，可用 `--font /path/to/font.ttc` 指定；没有可用中文字体时标签仅显示 F 编号。

下次可直接说：

> 用 F25 空心双线、F34 疏漏点阵、F37 缝线断笔各做一张原创横向片头，片名与场景重新设计。保留三种不同的笔画构造和私人笔迹，英文与细节依附字组留白。
