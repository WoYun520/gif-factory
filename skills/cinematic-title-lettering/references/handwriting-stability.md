# 十款手写字：选一款，换成你的片名

F41–F50 是这次新增的十款写法。每款都有用户提供的原稿、白底校准字稿、换句对照和完整场景。想沿用某款，就把原稿与校准图一起附给生图工具，说明只参考写法；不要把原图的旧句子带进新片名。

场景图、文案、字体参考和定稿字稿都可以自己提供。给了定稿字稿，就直接围绕它排版；给了照片，就按要求沿用照片。缺哪一部分，再补哪一部分。

F49、F50 分别是后来从三张钢笔原稿里选定的 01、03。它们接在原有八款后面编号，这组共十款，不重复计算早期的候选写法。

## 换片名时怎么做

打开对应原稿和校准字稿，确认要保留的笔势，再按新文案选主字、断行和场景里的位置。只有原本靠长竖、长锋或长钩区分的款式才延长实际笔画，其余款保住短收笔。完整场景继续按[片头做法](film-title-frames.md)处理；要多款各配一个片名和场景时，分别做独立图，再排成两列总览，图下标编号、字体名和片名。

把新图和原稿并排看：先逐字核对文案，再看粗细、转弯、空隙和长短。出现参考图里的旧字、缺偏旁或悬空的长钩，就只修对应位置，保留已经对的笔势与画面。不要因为换了颜色或场景，就把相近的写法算成新的类别。

## 准备生图输入

脚本可以整理片名、对应两张字稿和这款的写法。只准备输入，不调用外部 API。

```bash
# 白底字稿
python3 scripts/prepare_lettering.py --style F49 --title "把心事交给晚风" --break-after 3

# 完整片头：场景用文字描述，缺的画面由生图工具补
python3 scripts/prepare_lettering.py --style F50 --title "山河不急我也不急" --break-after 4 --scene "清晨河谷，淡色天空留给字，右下有一条小路" --out title-input.json
```

把输出的 `imagegen_args` 交给当前可用的生图工具即可。图和规则都在同一个 Skill 内，搬动整个 Skill 后脚本会重新解析路径。用户有现成照片或定稿字稿时，按用户给定素材制作，不用文字描述代替它们。

## 这次测到了什么

此前八款留有「等风来」「灯亮了我们就回家」两轮样张；十款又统一写了「雨停了」「把日子写成一封信」。后一轮共生成 12 张，选用 10 张，每张里有一短一长两组文字，不能当作两次独立生成。F44、F46 重试后仍偏规整，继续做新句子时要重点对照原稿。

本组还各做了一张独立场景。制作中修正了「四季」误入「月亮」、「日」偏似「月」和一张画幅偏窄的问题，场景提示词里保留了修正步骤。这些是参考图、提示词和实际样张，没有做模型权重微调，也不能保证任意新文案都一次写对。
