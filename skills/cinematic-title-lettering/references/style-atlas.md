## 换字时可直接检查的例子

- **01 上幅，荧光网点块字。** 左侧主字高起并下探，中间字压低，右侧字收紧。先决定哪个新字适合当主字，再用收尾长笔和空位放副题。网点跟随笔画内部，保持闭口、内孔和分离的小笔完整。
- **03 上幅，石墨瘦字。** 骨架竖长，局部干裂，落笔黑团集中在转折。保留字里空隙，按字的结构调整相邻字的高低差。以黑白字标对照，检查石墨纹理是否把笔画接成一片。
- **04 中幅，宋体骨架与细横穿插。** 「无」撑高左侧，「事」收窄并下沉，「发」斜插，「生」用上挑长笔收尾。新片名可迁移高低和咬合关系，只有字本身具备成排横画时才把细横密排放进去。
- **05 中幅，朱红宽刷字。** 用粗短笔搭厚重轮廓，留出疏密分明的内孔，边缘缺口沿真实笔势分布。不同字的宽度由偏旁和整体字块共同决定。
- **15 中幅，细锋长斜线。** 以一两笔超长斜锋带动横向阅读，短笔集中在少数几处，转折尖锐。换字时根据可延长的撇、捺、竖钩重做动线。
- **20 上幅，多色蜡笔字。** 先定正文的两行阅读顺序，再用两色拆分字块。浅色细描线顺着外形走，副题和小图形落在空隙里。正文在缩小后仍应读得出来。

## 另外十二种可指定的字形方向

| 风格与参考 | 换片名时保留的规则 |
| --- | --- |
| **斜插中英拼块** · [02 上幅](../assets/style-samples/02-01.jpg) | 横排中文拆出错落的厚块，利用字间凹位斜插英文。先保证中文连读，再让英文在空隙中形成第二层节奏。 |
| **长引笔与错位小字** · [01 中幅](../assets/style-samples/01-02.jpg) | 一根细长引笔先横穿留白，再接稀疏的主字。将小号副题错位放在末端下方，让字标重心偏向一边。 |
| **折线竖排** · [02 中幅](../assets/style-samples/02-02.jpg) | 字从上往下沿斜轴移动，用转折笔承接视线。副题放在折线内侧留下的楔形空间。适合短标题。 |
| **竖写加标注引线** · [03 中幅](../assets/style-samples/03-02.jpg) | 竖排主字作为骨架。细引线从字间空位横向伸出，连接用户给出的时间或短注。引线轻于主字，标签保持清晰。 |
| **粉笔衬线字** · [03 下幅](../assets/style-samples/03-03.jpg) | 保留端正的衬线骨架和清楚的横竖关系，用粉笔粒度处理笔缘。可用一条短斜线带出副题。 |
| **刮痕阶梯字** · [04 下幅](../assets/style-samples/04-03.jpg) | 让每个字依次下落，沿少数方向拉出细刮痕。字内保留明确的短直线和锐角。尾字附近给小副题留空。 |
| **双列错位行草** · [07 中幅](../assets/style-samples/07-02.jpg) | 两列起落错位，一列的长撇伸入另一列的空位。先按词组分列，再设计能穿插的长笔，让两列仍有明确读序。 |
| **小图嵌入字间** · [09 下幅](../assets/style-samples/09-03.jpg) | 让小图进入某个字旁边的开口或两字之间，图形大小接近局部偏旁。保留主体文字的辨识度，用另一根长笔拉开纵向尺度。 |
| **宽幅飞白书写** · [11](all-styles.md#参考图-11) | 用饱满宽笔搭出横向的大轮廓，提按起伏决定每个字的高低。沿笔势保留内部飞白，并把最后一笔向右拉长。 |
| **长标题斜叠行** · [13 下幅](../assets/style-samples/13-03.jpg) | 先按词义切成短行，再用不同字号和倾斜幅度堆叠。让一两根长笔跨进相邻行的空白，缩小时仍能按顺序读全标题。 |
| **沿弧线排字** · [16 右上](all-styles.md#参考图-16) | 以一根有起伏的手绘弧线组织阅读路径。字的角度跟随局部切线变化，转弯处重新分配字距。适合短句和手写副题。 |
| **中文切角块字叠细手写** · [19 上幅](../assets/style-samples/19-01.jpg) | 中文主标题用大块面和锐利切角分行，细手写跨入字间或外缘。用尺度和色差保持两层的读序，关键偏旁周围留空。 |
