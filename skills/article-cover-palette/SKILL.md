# 文章封面配色 · 100套

按文章要表达的意思挑颜色，再把颜色用到合适的画面上。100套是可选配色，不是100种文章分类，也不是100个固定版式。安装、用法和直观看图见[大白话说明](README.md)。

这套 Skill 有三部分：

1. **配色表**：[100套配色表](references/palette-table.md)，也提供[CSV表格](references/palette-table.csv)和[色卡＋色号图表](references/color-cards.md)。每组都有编号、名称、HEX、适用题材、情绪、标题与底色的搭法。机器数据在 [catalog.json](references/catalog.json)，100张已制成的色卡在 `assets/cards/`。
2. **判断规则**：[从文章选配色](references/article-to-palette.md)。先读懂文章在表达什么，再挑颜色，不凭一个关键词决定整张封面。
3. **出图模板**：[正文窄卡](templates/palette-card.md)与[文章封面](templates/article-cover.md)。用真实色号、标题和素材填入模板后继续成图。

## 先看用户要什么

- 只问“这篇文章配什么色”：给一套主推、最多两套有明显区别的备选，说明内容依据和标题/底色搭法，不自动生图。
- 要“配色卡、正文色卡”：默认 **3:1、1200×400**，沿用已经选定的窄横风格。100套放同一篇文章时保持这类紧凑高度。
- 要“文章封面”：按目标平台或用户指定比例制作；未指定可从 **5:2、1500×600** 起步。封面按文章重新构图。
- 用户指定编号或HEX时直接使用；给了自己的场景图、照片、字稿或字体要求时一起纳入，保留其明确要求。无人物素材时可用主题物件、图解或色块组织画面。

配色卡上的块字是色卡展示风格。文章封面的字体、主体和气氛跟着内容选，不把每篇都套成同一种大字海报。

## 先定画面，再选配色

文章先按教程、工具介绍、分析、经验、清单、故事情绪等少数用途判断；热点与新闻补上语气和事实边界。再看具体题材与情绪，不把“AI”固定等于蓝灰色。常见用途见[判断规则](references/article-to-palette.md#文章只用少数几类入口)。

用户已有封面、喜欢的版式或正在使用另一个封面Skill时，先看主体、字体、材料、留白和允许改色的范围。把原配色也作为候选；原方案更合适就保留，说明理由，不强行从100套里替换。用户明确指定配色时按指定执行。

与其他封面Skill配合时，各自承担已有职责：对方组织画面，这里提供候选配色、颜色分工和读字检查。按其原说明与许可使用，不自动安装或复制第三方风格库。没有其他Skill也能用本包模板完成封面。

## 按内容选一组

先读[判断规则](references/article-to-palette.md)，提炼简短内容摘要、表达目的、题材、情绪和视觉强度。运行 `scripts/palette.py vocabulary` 可查看目录里的常用标签。

把这些信息写成一个 brief JSON，再运行：

```text
python3 <当前Skill目录>/scripts/palette.py select --brief <brief.json> --limit 3
```

脚本按结构化判断查表和排序，不会自行读懂全文。先由助手理解文章，再用脚本辅助挑选；对用户的解释要引用文章的具体内容，不能只复述得分。候选还要与已选材料、构图、用色数量核对，得分最高不等于成图最好看。

查指定配色用 `show 30`；浏览全表时才读完整配色表。表中“适用题材、情绪、用法”是设计建议，HEX与原清单一致。61—79组的单色名称是为方便阅读补上的描述，详见[数据说明](references/data-notes.md)。

## 用模板继续制作

用 `scripts/palette.py prompt` 填模板，返回完整提示词、配色角色和应使用的参考图。例如：

```text
python3 <当前Skill目录>/scripts/palette.py prompt --id 30 --mode palette-card --out <输出目录>
python3 <当前Skill目录>/scripts/palette.py prompt --id 65 --mode article-cover --title "从营收到利润，还差哪一步" --out <输出目录>
```

完整参数和自定义颜色示例见[脚本用法](references/script-usage.md)。脚本只准备配色与提示词，不调用画图服务。用户要成图时，继续使用当前环境可用的生图或排版工具，完成实际图片；只有提示词时不得说图片已做好。

封面brief可写`visual_direction`（画面方向）、`visual_subject`（主题主体）、`palette_scope`（哪些地方改色）和`preserve`（必须保留的要求）。明确写进最终提示词，不能只有配色指令。保留原配色的任务直接沿用原方案制作，不必运行编号查表。

做窄卡时，`assets/style-reference.jpg` 只供版式与字形参考，所有编号、名字、色号和色块换成目标配色。文章封面不默认套用这张色卡的布局。用户图片按内容、字稿或风格分别标明用途；需要传给生图工具的本地图先查看。

## 看一眼再交

- 逐字核对标题、编号和HEX；尺寸看导出的实际像素，不能只看提示词写了什么。
- 缩到390像素宽检查色名与色号。标题、正文和每个色块上的文字分别检查对比；相近颜色用辅助字色或小衬底解决，并说明新增字色，不改原色号。
- 色块原值以目录HEX为准；AI色卡只作视觉预览。需要可取色的纯色文件时，用精确色号绘制，不把AI近似色或JPG像素当成原始色值。
- 交付实际图片和简短用法。新增或重绘后才重查受影响的内容；不要把结构校验通过称为模型训练完成或所有文章都已验证。
