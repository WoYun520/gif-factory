# 动作与验收

## 每个动作记录五个节点

预备 → 触碰 → 承重/持有 → 释放/交接 → 收势。不是每个动作都等时，也不是每段都要停住。关键接触没有被画出来，就补接触帧或改动作，不能用模糊、降帧和闪切隐藏。

- **捞灯**：重心和躯干靠近水面，手到手柄，握住后灯才离水，提起时肘和身体共同回收，灯再摆一下。道具先独立飞起、手随后追上，判为失败。
- **骑行**：脚在踏板上，膝盖连续弯曲，脚踏相位和轮转/行进协调；停靠时不继续原地猛踩。身体起伏、目光和转向按事件设计。腿的数学约束正确但人物像机器人，仍未通过表演。
- **递信**：发出方持有 → 双方接触 → 接收方持有 → 发出方收手。每一刻只有一封信。收信住户的反应属于动作，不用无来源的几何手掌代替完整叙事。

## 按三个尺度看

1. 正常速度：不靠讲解能否看懂谁在做什么、动作为什么发生。
2. 原帧率局部：接触前后各至少数帧；看手/柄、脚/踏板、臀/坐垫及轮/地面，检查持有状态切换、道具数量、遮挡和重心。
3. 同时间对照：原参考和重建用同一显示尺寸，核对身体/车架比例、动作幅度、场景间距、速度变化和短停长度。重新设计的作品比较方法而非像素相同。

## 角色经过道具

排走位时，先看角色及随身物、影子或水纹的活动范围会碰到哪些轮廓。只为发生交叉的地方拆层。同一道具可以有前后两部分。例如手伸进篮子时，篮底在后，手和萝卜居中，近侧篮沿在前。手提出篮口后，再按实际空间关系露出萝卜。

- **新画的场景**：把会挡住角色的草叶、绳子或栏杆单独画在透明层上，保留叶间、栏杆间的空隙。背景留出该前景的位置。角色从道具前面经过时，顺序相反。
- **已有完整底图**：沿实际交叉处提取靠近镜头那一侧的轮廓，保留纸边和孔隙。先画底图、角色与相关效果，再用这块遮罩贴回原图的对应像素。遮罩随所属景物一起裁切、缩放和移动；需要独立视差的前景须从底图分离。
- **鸭子游过芦苇**：从远到近画池塘、水纹、鸭子、近岸芦苇。鸭身在叶间可见，水纹也止于叶片；鸭子离开草丛后，身体轮廓应完整。若前后关系在同一镜头中确实改变，在角色实际绕过道具的那一帧交接。

**整片渲染前逐处验收。** 在分镜的 `occlusion_crossings` 里列出每次交叉。用成片的机位、图层、帧率和特效试渲该段，范围从相交前几帧到完全分开后几帧。对着正常速度短预览看一次，再按原始分辨率逐帧看进入、遮挡最深和离开之间的所有帧。重点看遮挡方向、叶缝是否透出角色、细边闪烁、随镜头漂移，以及水纹或影子盖住前景。构图或时序改变后重查受影响的区段。

可用播放器逐帧前进，或用下面的命令导出连续原帧。例中 12–35 是试片内从 0 计数的源帧号，共 24 张；为每段使用单独的空目录并换成实际帧号。

```sh
mkdir -p review/pond-entry
ffmpeg -v error -i shot-preview.mp4 -vf "select='between(n,12,35)'" -fps_mode passthrough -start_number 12 review/pond-entry/%06d.png
```

每处记录镜号、实查帧段、证据位置和视觉结论。初始为 `not_tested`；发现穿帮记 `failed`，修好后重渲同一段并复查，合格记 `passed`。全部交叉通过后再开始整片渲染。没有交叉的镜头填空列表。记录和抽帧本身都不代表通过。

分层与局部遮挡的做法参考 [lemomo-ai/lemo-animi](https://github.com/lemomo-ai/lemo-animi)，上述鸭子与篮子的检查适用于本系列的纸艺镜头。

## 放行条件与证据

- 技术：实际解码、尺寸、帧率、时长和帧数检查通过。
- 视觉：正常播放和关键原帧都检查；记录具体不足，不用“整体自然”代替证据。
- 用户：未给认可就写“待确认”；用户已指出不自然的版本继续列为反例。

接触、身份、比例或重心仍明显错误时，停止扩展同一方法，交代限制并重做该动作。不要把大量角色、更多装饰、配乐、精细纸纹或更短时长当作动作已修复。

## 计划文件

`templates/story-plan.json` 只是示例字段，不是强制照搬的剧情。每个关键动作填入实际帧/秒、可见锚点或测试截图、观察者结论。验收字段初始为待测试，不能随文件生成自动标记通过。

## 已定位的失败帧

用本工具以24fps复查送灯14秒版本的2.5–3.0秒：约2.75–2.83秒可见两套头部/耳朵轮廓叠在一起。这是姿态交叉淡化，不是身体连续转动；正常播放会形成飘、软和跳变的感觉。这个案例说明仅看首中末帧或稀疏总览会漏检。之后动作测试须包含姿态转换的中间帧，不再把交叉淡化当作修复路线。
