## 镜头与金额

| 时间 | 画面与作用 |
| --- | --- |
| 0–4.167秒 | 借款人在柜台签约，抛出100万元从哪里来的问题 |
| 4.167–11.933秒 | 同一柜台推出存款与欠款两份不同凭证，各增加100万元 |
| 11.933–18.867秒 | 天平比喻等额资产负债变化，本笔净资产变化0元 |

| 34.833–42.733秒 | 回到柜台，保持90万元存款和90万元欠款 |

金额是机制演示假设，不是某银行真实产品。本例先不发生消费转账，直接用这笔本行存款归还10万元本金；省略利息、费用与其他资产负债。银行原有资金及借款人原有其他净资产未知。天平为比喻，地图不是本例已经发生的转账。详细状态在finance-model.json中，新选题应另建模型。

## 依据与检查边界

机制依据为英格兰银行的[货币如何创造](https://www.bankofengland.co.uk/explainers/how-is-money-created)和[现代经济中的货币创造](https://www.bankofengland.co.uk/quarterly-bulletin/2014/q1/money-creation-in-the-modern-economy)。本片不使用英国历史监管比例、利率或货币占比推断其他国家的具体制度。

此样片已做工程显示检查、手机尺寸与关键帧检查、金额同步检查、实际文件解码与音量技术检测。声音技术检测不能代替人耳逐段试听；v0.1样例也不代表所有题材或生成服务都已验证。

本目录提供可观看媒体、字幕和金额模型。生成画面和字体渲染后的像素包含在媒体中；不分发本机字体文件、个人原视频、凭据或含机器绝对路径的内部工程记录。需要复作时按Skill重新准备合法可用的字体、图像与声线，并保留可编辑工程。
