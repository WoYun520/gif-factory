## 每个完整案例目录有什么

- `film.mp4`：完整成片。
- `cover.png`或`cover.jpg`：同版封面；`preview.gif`为轻量静音节选。
- `captions.srt`：与现有旁白对时的字幕。
- `finance-model.json`或`model.json`：金额、容量、状态或切点等演示条件。
- `README.md`：讲解范围、镜头作用及复作边界。
- `CREDITS.md`：图像和声音来源、第三方许可及可复制的配乐署名。
- `media.json`：公开文件的规格、哈希和检查范围。

本次整理沿用已有成片及旁白，新增公开说明、字幕转换和预览；不将旧视频标成新渲染结果。案例目录不提供完整渲染工程或通用动画引擎。制作新题目时按Skill建立自己的可编辑工程、模型与检查记录。
