## 看什么

- 摄影纸艺：接触、锁止、转动、复位，以及凭证、账目和资金变化。
- 复古档案记录：把容量与价格记到账纸里，摄影、纸页、打字和红笔共同讲解。
- 彩色贴纸：同一组物件持续操作，通过对齐单位、付款和补贴路径解释结果。

档案与贴纸的单价片段接着同一组价格讲下去，便于比较两种画面方法。前几期保留方形主画面与上下留边，后期为原生竖屏。独立完整案例见[上一级目录](../README.md)。

这是风格与节奏展示，各片段的结构类型、金额、价格和省略项沿用原例，不能把不同片段拼成同一笔交易或推断现实产品。价格与金额是演示条件；暖色商品照片是合成插图，不是真实史料。
